# Red Flags

| Shortcut | Response |
|---|---|
| Small means no review or gate. | Use the bounded lightweight criteria; handoff guarantees remain. |
| The old approval still matches while we reopen review. | Start a new run and Pending decision before work; the old run cannot authorize it. |
| Hash it again after CLEAR. | Compare with the reviewer's recorded hashes. Changed inputs need renewed review. |
| A specification is optional to read. | Optional means absent; a supplied normative specification is mandatory in either mode. |
| The review is obvious from its filename. | Resolve exactly one literal declaration from the plan directory. |
| A code example says APPROVED. | Only the actual terminal decision in the current run governs. |
| The planner can verify its own correction. | Full review needs a fresh independent verifier; local fallback remains explicit. |
| Record the controller as its own verifier to finish the run. | The gate rejects one identity in `Verdict by` and `Recorded by`. Obtain a real reviewer or use the labelled local fallback. |
| Leave the run counters at their template values. | The gate requires filled, in-budget counters and at least two review dispatches for full mode. |
| Switch venue or approved route silently. | Respect the recorded venue/rule; resolve an unavailable required path explicitly. |
| Retry until an agent gives CLEAR. | Preserve run counters and stop at the bounded limit. |
| A local hash comparison is enough when the script is missing. | Restore the tested gate or stop. No manual bypass. |
| Put * in the repository-root .gitignore. | Put it only in the task-folder .gitignore and verify exclusion. |
| Change Git's info/exclude or untrack artifacts automatically. | This workflow uses the folder-local rule; preserve existing shared/tracked state. |
| Commit the ignored handoff to share it. | Transfer reachable files only within explicit user authorization. |
| An outside-folder reference is invalid. | Check its actual target; valid repository and specification paths are allowed. |
| Fix the normative specification to fit the plan. | A task-owner requirements decision is needed; revisers do not redefine the source. |
